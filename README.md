# Ethereal

A modern web application for exploring and interacting with NFTs, built with Next.js 13+ and integrating with blockchain technology.

## 🚀 Features

- Responsive landing page with smooth scroll navigation
- Mobile-friendly design with hamburger menu
- Animated UI components using Framer Motion
- Wallet integration support (upcoming)
- NFT exploration interface
- SEO optimized

## 🛠️ Tech Stack

- **Frontend:** Next.js 13+, TypeScript, Tailwind CSS
- **Animations:** Framer Motion
- **Web3:** RainbowKit (planned)
- **Styling:** Tailwind CSS, CSS Modules
- **Icons:** Lucide React

## 🏗️ Installation

1. Clone the repository:
```bash
git clone https://github.com/izzaafkarina14/etheral-ArctureLab
```

2. Move to the folder `ethereal`:
```bash
cd ethereal
```

3. Install all teh package:
```bash
npm i
```

4. Run the project:
```bash
npm run dev
```
